A deterministic Python program that writes one original one-line joke to `/output/entry.txt`. The line sets up a bank fraud call and pays off with the reveal that the suspicious activity was finally trying to save money.

## Run

```sh
python3 -P -s main.py
cat /output/entry.txt
```
